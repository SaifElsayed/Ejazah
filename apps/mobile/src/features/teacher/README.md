# teacher

Teacher-only features. Arrive by phase: application (Phase 1); payout-setup (Phase 1, shown right after approval; teacher invisible until the gateway verifies the account); packages, availability (Phase 2); isnad, granting (Phase 4). There is no earnings or balance screen: the gateway settles directly to the teacher and the platform holds nothing (ADR 0007).
