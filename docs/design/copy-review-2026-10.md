# Copy review — October 2026

Every string the catalogue (`apps/mobile/src/i18n/`, `apps/admin/src/i18n/`) holds beyond what a
board draws, Arabic and English side by side, for the owner to accept or edit. The boards are the
copy's source; where a board draws one form, the catalogue completed the others (ICU plural and
select branches, the second provider, the other star labels, the empty states drawn on 2026-10-17
and the admin dialog variants of `screens.md` §24). Nothing here changes a board. A row is accepted
by leaving it; an edit is a change to the key in both files, then `pnpm check:i18n` and
`pnpm check:i18n:admin`.

ICU forms: Arabic uses one · two · few (3–10) · many (11–99) · other, with `#` for the number;
English one · other. «zero» branches exist only where a board draws a zero.

## 8 · Noted, no string to review

- «حساب Google نفسه» (SignOutSheet) writes the brand in Latin while `account.providers.google` is
  «جوجل»; the new Apple sentences follow the Latin form. One convention to pick.
- `student.home.startsIn` is relative time; a formatter may replace the key (open item A1 23).
- The English register follows MainEn and the two English admin boards; every other English value is
  a translation without a board (open items A1 32, C 35).
