# Component contracts

A contract is the props a component accepts and the decisions it refuses to delegate. If a screen
needs a colour, a font or a radius, the answer is a new variant here, not a style override there.

The visual specification of every component is its block in
`frames/ds/ijazah/components.css`; the boards in `frames/` are drawn with it, so a component is
right when it matches the board pixel for pixel. The phone app's contracts are typed in
`apps/mobile/src/design/primitives/` (ADR 0020 D4); the admin panel implements the same contracts on
shadcn/ui themed by `apps/admin/src/design/tokens.css` (ADR 0014 D1). Every token name below is a key
of `packages/tokens/tokens.json`.

Conventions shared by every component:

- **Touch.** Every control is at least `size.touch` (44) tall and wide on the phone; the admin
  panel's compact density (`data-density="compact"`) brings controls to 36, never below.
- **Tokens only.** A component reads semantic colours (`color.light` / `color.dark`), never the
  palette, and never a literal (R-MOBILE-4, enforced by lint).
- **Direction.** Start and end, never left and right (R-MOBILE-5). Directional icons
  (`directionalIcons` in `icons.ts`) mirror in RTL; an `ltr` run (email, code, reference) is
  isolated inside Arabic.
- **States.** Hover (pointer only, `color.hover` / `color.primary-hover`), keyboard focus (one ring,
  `shadow.focus`, never on mouse click), pressed (`motion.press-scale` at `duration.fast`),
  disabled (`opacity.disabled`, no animation). Transitions use `duration.fast` and
  `easing.standard`; entering surfaces use `duration.base` (`easing.enter`), sheets `duration.slow`.
  Reduce-motion turns every animation off.
- **Accessibility.** A control without a visible label carries `accessibilityLabel`; a state a
  screen reader can announce (selected, disabled, expanded).

## Checklist before a component ships

- Reads correctly in RTL and LTR.
- Reads correctly in light and dark.
- Every colour comes from a semantic token; every size from a token.
- Touch targets meet the minimum (44 on the phone, 36 compact).
- Arabic and English copy both fit without truncation at the longest string.
- Has an accessibility label, and a state a screen reader can announce.
- Matches its board in `frames/` and its block in `components.css`.
