# Product decisions from the screen inventory — for the owner, October 2026

What the inventory of 2026-10-17 (`screens.md`, `open-items.md`) found that only the owner can
settle. One row per decision: what is open, the options, and a recommendation with its reason. The
recommendation is not a decision; nothing below has been applied. Once a row is decided, the
consequence is a board edit (`source/frags/`), a key in the catalogue, a line in `screens.md`, or
an SRS amendment, as the last column says. The states that followed an approved pattern were drawn
in the same pass (fifteen boards, `screens.md` §24 and the states tables); the copy that was
completed beyond the boards is `copy-review-2026-10.md`; the data and configuration consequences
are ADR 0021.
