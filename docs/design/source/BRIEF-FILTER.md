## Pattern A — filtering a list (narrowing by attributes)
- One row: `.search-row` = `.input-group` search field + a filter trigger
  `<a|button class="icon-btn icon-btn--surface filter-trigger [filter-trigger--active]">{{icon:filter:md}}[<span class="filter-trigger__count">N</span>]</a>`.
- Opening it shows `.dropdown` inside the `.search-row` (`search-row--open`), with `.dropdown__group`s, each a
  `.dropdown__title` and an `.option-grid` of `<button class="option [option--selected]" role="radio"><span class="option__mark"></span>label</button>`;
  `.dropdown__footer` with a primary «عرض N …» and a ghost «مسح». On the phone add `<div class="scrim scrim--soft"></div>`
  right after `</main>` so the page behind dims.
- Applied filters: `.filter-chips` of `<button class="chip chip--selected chip--removable">label{{icon:x:xs}}</button>`
  plus a «مسح الكل» link; the trigger then shows its count.
- Every old filter chip/button row that narrows a list is replaced by this. Keep the same filter fields the board had
  (e.g. AdminUsers: الدور، حالة الحساب، الجنس، القُصَّر) — they become dropdown groups.

## Pattern B — sections of a list (which subset to show)
- `<div class="category-tabs" role="tablist">` with `<button class="category-tabs__item [category-tabs__item--selected]" role="tab" aria-selected>label<span class="category-tabs__count">N</span></button>`.
- Replaces a segmented control or chip row whose job is to switch between subsets of the SAME list
  (جارية/منتهية، قيد المراجعة/تم البتّ، الكل/مفتوحة…). Counts move into `category-tabs__count`.

## Do NOT change
- Segmented controls inside forms or dialogs that pick one value (gender, document type, language, track, duration,
  action type in a dialog such as AdminSuspendDialog «إيقاف/سحب/حظر», AdminDecisionDialog «رفض/طلب معلومات/حظر»,
  AdminDisputes' party picker الطالب/المعلم).
- Chips used for multi-select inside forms (ApplySubjects subjects, SlotEditor days), choice rows, name tags in the
  chain editor (AdminCredentials/AdminCredentialCorrect name chips with ×).
